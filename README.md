# 北京大学文物与博物馆专硕考研资料库

这是一个面向北京大学考古文博学院文物与博物馆专业硕士（MCHM）考研的公开资料整理项目。内容以北大官方招生通知、学院本科/研究生教学手册、国内重点大学培养方案、政府法规、公开课程和可复核的电商书目信息为主，目标是把“信息搜集”转化为可执行的复习链路。

## 项目内容

- [完整复习链路与课程—考点映射](outputs/北大文物与博物馆专硕考研资料与复习链路.md)
- [官方及重点大学电子资料](outputs/electronic_materials/)
- [电商书目信息核验记录](outputs/electronic_materials/marketplace_evidence_2026-09-30.md)

电子资料目录中包含：

- 北京大学考古文博学院本科生教学手册（2023）
- 北京大学考古文博学院研究生教学手册（2022）
- 浙江大学文物与博物馆学本科培养方案
- 南京大学文物与博物馆学（0651）专业硕士培养方案
- 复旦大学文物与博物馆学系研究生教育年度报告
- 《博物馆条例》、2024年修订《文物保护法》网页存档
- 北大拟录取公示等招生信息资料

## 推荐使用顺序

1. 先阅读主文档第1–3节，确认北大考试科目、348方向和核心书目。
2. 阅读北大本科/研究生教学手册，按课程名称建立专题框架。
3. 使用主文档中的13周计划、课程—考点—书目—答题产出表推进复习。
4. 用公开课程视频补概念和案例，但不把视频中的押题、分数线或“指定书目”当作官方信息。
5. 报名前重新核对北大研招网、学院招生目录和当年复试细则。

## 来源与版权说明

- 官方招生文件、学校培养方案、政府法规和公开课程链接优先使用原始来源。
- 主文档已经区分官方信息、公开经验、机构整理和未核实线索。
- 仓库不收录明显盗版教材扫描件、网盘整本书、绕过付费下载的文件或个人隐私资料。
- 目录中的教材购买链接仅用于书目核对和正版/二手购买检索；库存、价格和卖家资质会变化。
- PDF、网页存档和视频的版权归原作者、学校、政府机构或平台所有，本项目只做考研研究用途的索引和整理。

## 更新原则

每次更新建议记录：

- 检索日期；
- 原始网址；
- 来源类型（官方、学校、政府、课程平台、经验帖、电商）；
- 是否下载、是否核对作者/出版社/ISBN；
- 对北大348初试或复试的具体用途。

## 重要提醒

北大每年可能调整考试科目、招生人数、方向名称、推免比例和复试规则。本仓库不能替代当年官方招生目录，也不构成录取承诺。
